# 人类数据基线

这个文档说明仓库里的人类数据从哪来、怎么导入、用什么指标和人类比较，以及结果怎么读。

## 为什么需要它

只比较机器配置，只能回答「哪个提示词更好」。要回答「机器的想法在人类里算什么水平」「我们的自动指标到底量到了人类说的那件事没有」，必须引入人类数据。这里做两件事：

1. **指标校验**：在同一批人类作答上，把本仓库的自动语义距离和人类评分者的打分做相关，并和原论文的 GloVe 距离放在一起对照。
2. **位置定位**：把发散联想任务（DAT）的人类参与者分数分布算出来，看机器输出落在第几百分位；在 AUT 上把机器想法和同题人类作答放进同一个嵌入空间直接比。

## 数据来源

三个公开数据集，全部来自 OSF，导入后放在 `data/human/`（约 4 MB），原始文件不进版本库。

| 文件 | 内容 | 规模 | 出处 |
| --- | --- | --- | --- |
| `semdis-aut.json` | 替代用途任务（AUT）的人类作答 + 3~4 名评分者的 1~5 分 | 7,097 条，题目 box / rope / brick | Beaty & Johnson (2021), Behavior Research Methods；OSF `gz4fc` |
| `semdis-wa.json` | 词语联想任务的人类作答 + 创造力/新颖性/恰当性评分 | 6,456 条 | 同上，Study 4.1/4.2/5 |
| `olson-dat.json` | 发散联想任务（DAT）参与者的原始 10 个词 + 原论文 DAT 分数 + 部分人的 AUT 评分 | 8,998 人（Study 1a/1b/2） | Olson et al. (2021), PNAS；OSF `kbeq6` |

引用：

- Beaty, R. E., & Johnson, D. R. (2021). Automating creativity assessment with SemDis: An open platform for computing semantic distance. `Behavior Research Methods`, 53, 757-780.
- Olson, J. A., Nahas, J., Chmoulevitch, D., Cropper, S. J., & Webb, M. E. (2021). Naming unrelated words predicts creativity. `PNAS`, 118(25), e2102340118.

## 导入流程

`npm run human:fetch` 会下载上述原始文件到 `runs/cache/human-raw/`（已 gitignore），校验 SHA-256，然后转换成 `data/human/*.json`。表格解析用的是仓库自带的极简 xlsx 读取器（`src/core/xlsx.ts`，zip + DEFLATE + SpreadsheetML 子集，零依赖），因此导入阶段也不需要第三方库。

校验和不匹配会直接报错；如果上游文件确实变了，用 `--update-hashes` 打印新值再人工更新脚本里的常量。转换后的文件记录了每个来源的 URL、校验和与记录数，`npm test` 会检查记录规模、评分范围等基本不变量。

## 指标定义

### 语义距离（`src/bench/human.ts`）

对每条作答，在题目内部（AUT 的 box / rope / brick，词语联想的每个线索词）计算：

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| `toItem` | 1 − cos(作答, 题目词) | 原论文 SemDis 的口径，用于和 `pub_glov` 对照 |
| `minOther` | 1 − 与同一题其它作答的最大余弦相似度 | 「离别人最近有多远」 |
| `meanKOther` | 与最近的 K=3 条其它作答的平均距离 | 是否只是重复了某一片常见答案 |
| `meanOther` | 与同一题其它作答的平均距离 | 集合层面的离散程度 |

`pub_glov` 是原论文用 GloVe 840B 算出的距离（Study 1 用乘性组合 `glov_m`），只作为参照行：它和人类评分的相关是本仓库自动指标要达到的量级。

### 与人类评分的一致性

人类评分是 1~5 分的顺序量表，不同题目、不同研究之间不可直接合并，所以相关性**在题目内部计算**，再用 Fisher z 加权平均得到总体估计；同时给出「题内标准化后合并」的 Pearson 作为稳健性检查。`responseLength`（作文字数与评分）单独列出，用来检查评分是否被答案长度带着走。

### DAT 分数

与原论文一致：取前 7 个有效且不重复的单字词，算 21 个词对的平均余弦距离，乘 100。在本仓库里用本机嵌入模型（`qwen3-embedding`）重算，因此人类和机器在同一把尺子上。原论文的 `datPublished`（GloVe/word2vec）保留下来做两件事：验证本仓库这把尺子（两套分数的相关），以及给出全样本（8,998 人）的分布参照。

### 机器 vs 人类的比较

- 机器想法先用模型压缩成 2~6 个词的用途短语（`condense:<task>` 调用，走 `ChatClient` 缓存与审计日志），再和人类短语作答比，避免「长句子 vs 短语」的长度混淆；压缩前的原始距离也一并记录。
- 位置用百分位表示（机器均值/最大值在人类分布中的位置），效应量用 Cliff's δ 与优势概率 P(机器 > 随机一名人类)。
- 只有题目措辞相同才做同题比较。中文 AUT 任务没有对应的人类数据，`aut-brick` 一行标注为跨语言稳健性检查，不作为同题结论。

## 命令

```bash
npm run human:fetch                              # 下载 + 校验 + 转换（需要网络）
npm run human -- --stage validation              # 自动指标 vs 人类评分
npm run human -- --stage dat --dat-sample 2000   # 人类 DAT 分布（本机嵌入重算）
npm run human -- --stage compare --run runs/main-live
npm run human                                    # 三个阶段全跑
```

产物写到 `runs/human-<时间戳>/`：`summary.json`（机器可读）与 `report.md`（人可读）。产物写到 `runs/human-<时间戳>/`：`summary.json`（机器可读）、`report.md` 与 `report.html`（内联 SVG 直方图，标出机器的位置）。

抽样与开销：默认从每个题目里按固定种子抽 600 条 AUT 作答、120 条词语联想作答，机器对比阶段每题用 900 条人类作答作参照（`--ref-limit`），DAT 抽 2,000 名参与者，合计约 1 万条文本；`--limit-aut` / `--limit-wa` / `--dat-sample` 可调，`--limit N` 同时设置前两者。这一阶段默认**不写嵌入缓存**（`--cache FILE` 可开启）：JSONL 缓存按 4096 维浮点存原文，上万条就是几百 MB，加载时的内存峰值比重新嵌入更麻烦；重跑要重新嵌入，这是刻意的取舍。

## 结果

下面是 [runs/human-baseline/](../runs/human-baseline/report.md) 一次完整运行的结果（语义空间 `qwen3-embedding:latest`，种子 20240930，抽样见报告开头）。逐题数字、每道题的相关系数和直方图见该目录的 `report.md` 与 `report.html`。

### 自动指标 vs 人类评分

| 数据 | 指标 | Fisher 平均 Spearman |
| --- | --- | --- |
| AUT（n = 1,800，3 题） | 与最近人类作答的距离 `minOther` | **0.518** |
| AUT | 与题目词的距离 `toItem` | 0.398 |
| AUT | 作答字数 `responseLength` | 0.404 |
| AUT | 原论文 GloVe 距离 `pub_glov`（参照） | 0.196 |
| AUT | 原论文 cbowu / cbows / cboww / tasa（参照） | 0.282 / 0.283 / 0.245 / 0.132 |
| 词语联想（n = 4,984，67 题） | 与题目词的距离 `toItem` | 0.279 |
| 词语联想 | 与其它作答的平均距离 `meanOther` | 0.337 |
| 词语联想 | 原论文 GloVe 距离（参照） | 0.379 |
| 词语联想 | 原论文 cbowu / tasa（参照） | 0.333 / 0.281 |

怎么读：

- 在 AUT 上，本仓库的嵌入距离比原论文的 GloVe 距离更贴近人类评分（0.40~0.52 对 0.13~0.28）；在词语联想上反过来：原论文 GloVe 距离 0.379 高于我们的 `toItem` 0.279，而我们的 `meanOther`（0.337）夹在中间。哪个语义空间更好取决于任务，不能一概而论。
- 「离最近的人类作答有多远」这一类指标（`minOther` / `meanOther`）在两套数据里都排在前列，形状正是本仓库新颖度指标用的那一种（1 − 最大余弦相似度）。
- 人类作答字数与评分的相关同样是正的（AUT 0.404、词语联想 0.268）：评分者也会给长答案更高分。长度始终是混淆项，读任何一列都要记住这一点。

### DAT：人类分布与机器位置

- 人类参与者 8,998 人；用本仓库嵌入重算了 2,524 人：均值 39.41、标准差 3.91、中位数 39.50（P10 34.70 ~ P90 44.07）。
- 同一批人的原论文分数均值 78.40（全样本 78.19）；两把尺子的相关是 Pearson 0.451、Spearman 0.370。
- 效标效度：本仓库重算的 DAT 分与同一批人的人类 AUT 原创性评分相关 Spearman 0.094（n = 721），原论文分数是 0.221。我们的尺子在这一项上更弱，差距落在抽样误差范围内，但方向上不能声称两者等价。
- 机器位置（同一把尺子内）：英文同题任务 `dat-en-7` 的 `engine` 配置得 40.67，在人类分布的第 63 百分位（Cliff's δ 0.25）；`zero-shot` 得 38.96，第 44 百分位。中文 DAT 任务（跨语言，只作参考）落在第 67~86 百分位。

### 同题 AUT：机器想法 vs 人类作答

| 任务/配置 | 机器与题目词的距离 | 人类同题均值 | 人类百分位 | Cliff's δ |
| --- | --- | --- | --- | --- |
| `aut-brick-en/engine` | 0.561 | 0.373 | 0.98 | 0.910 |
| `aut-brick-en/zero-shot` | 0.554 | 0.373 | 0.98 | 0.945 |
| `aut-box-en/engine` | 0.561 | 0.350 | 0.99 | 0.979 |
| `aut-box-en/zero-shot` | 0.394 | 0.350 | 0.76 | 0.441 |
| `aut-rope-en/engine` | 0.477 | 0.340 | 0.97 | 0.891 |
| `aut-rope-en/zero-shot` | 0.472 | 0.340 | 0.97 | 0.876 |

机器想法先被压缩成 2~6 个词的用途短语（比人类短语还短：机器短语约 4~8 个字符，人类 15~27 个字符），再和人类作答放进同一个嵌入空间。机器短语离题目词更远，也离任何一条人类作答更远（「与最近人类作答的距离」的百分位在 0.99~1.00）。由于 `toItem` 与 `minOther` 都与人类评分正相关，这个方向对人类评分者意味着「更新颖」，但**这不等于人类会给它高分**：被压缩后的机器短语仍然是模型措辞，风格与人类作答不同，而且本仓库没有让人类评价过机器想法。

## 局限

- 人类数据是英文被试；机器任务有中文和英文两套，跨语言的语义距离没有校准。
- 人类评分是顺序量表，自动距离是连续值：相关系数说明单调关系，不能把距离换算成分数。
- SemDis 的评分者只有 3~4 人，评分者间信度有限；本仓库按原表给的分值直接聚合，没有重新建模。
- 这些数据不能证明「机器超过人类」；它能回答的是「机器落在人类分布的哪个位置」和「自动指标是否量到了人类评分看见的东西」。
